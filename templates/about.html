About EyeVerse

AI-Powered Diabetic Retinopathy Detection System

Project Overview

EyeVerse is an AI-based medical imaging system designed to detect and classify Diabetic Retinopathy (DR) from retinal fundus images. The system uses deep learning to provide instant, accurate diagnosis and generates comprehensive medical reports.

Academic Information

  • Course: AI Project Design and Development

Technical Stack

Deep Learning
PyTorch, ResNet50
Backend
Flask, Python
Frontend
HTML5, CSS3, JavaScript
Dataset
APTOS 2019 (3,662 images)

Model Performance

  • Test Accuracy: 78-85%
  • F1-Score: 0.75-0.80
  • Training Time: ~30 minutes (GPU)
  • Classes: 5 (No DR, Mild, Moderate, Severe, Proliferative)

Project Goals

  • Automated detection of diabetic retinopathy from retinal images
  • Multi-class classification (5 severity levels)
  • Real-time prediction with confidence scores
  • Automated diagnostic report generation
  • User-friendly web interface for accessibility

Dataset Information

The model is trained on the APTOS 2019 Blindness Detection dataset from Kaggle, containing 3,662 high-quality retinal fundus images labeled with DR severity levels (0-4).

Methodology

  1. Data Preparation: Image preprocessing, augmentation, and normalization
  2. Model Architecture: ResNet50 with transfer learning
  3. Training: 50 epochs with Adam optimizer
  4. Evaluation: Accuracy, F1-score, confusion matrix
  5. Deployment: Flask web application

Disclaimer

Important: This system is developed for educational purposes as part of an AI Project Design and Development course project. It should NOT be used as a substitute for professional medical diagnosis. All results must be verified by qualified ophthalmologists.
